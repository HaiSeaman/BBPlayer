# BBPlayer 1.9.1

**一句话**：这是一个**瘦身 + 减负**版本——安装后体积从 **521MB 砍到 308MB**（少了 **213MB**，降 **41%**），播放视频时的 GPU 开销也降了下来；同时修掉 **7 个真实缺陷**（其中一个会让无边框窗口"关不掉"）。**没有加新功能**，就是让软件更小、更省、更稳。

---

## 📦 体积瘦身：安装后少了 213MB（521MB → 308MB）

三块独立的收益，都已用真实打包逐项核对：

| 瘦身项 | 省下 |
|---|---|
| **① 裁剪多余语言包**（55 个 → 只留中文 + 英文） | **−47MB** |
| **② 删除用不到的 WebGPU 着色器编译器**（`dxcompiler.dll` / `dxil.dll`） | **−26MB** |
| **③ 内置转换器换精简自编版**（153.5MB → 13.4MB） | **−140MB** |

**为什么能省这么多**：

- **语言包**：Electron 自带 55 个国家的语言文件，你只用中文，其余纯占地方。
- **WebGPU 文件**：那是"网页 3D 图形"用的着色器编译器，你只看视频，完全用不到（Electron 官方自己也删过这两个文件）。
- **转换器**：原来带的是"全量版 FFmpeg"，一大半功能用不上（光滤镜库就 30MB，而你一个滤镜都不用）。本版换成**用源码专门为你这个播放器编译的精简版**——只保留播放老格式（avi/wmv/rmvb/ts 等）真正需要的解码器和硬件编码。

> 转换器换新版后，**avi / flv / wmv / rmvb / ts / vob 等老格式照常能播**，功能一个没少；本机实测还成功启用了 **NVIDIA 显卡硬件编码**，转码更快。

## ⚡ 播放时更省 GPU（控制栏毛玻璃）

**问题**：画面底部那条控制栏用了"毛玻璃"效果（背景模糊）。你放视频时，控制栏**背后的画面每帧都在变**，这层模糊就得**每帧重算**——而控制栏默认是亮着的，只要你鼠标没移到底部再移开，它就**整场播放都亮着、整场都在烧 GPU**。

**修复后**：

- 视频一开播，若鼠标**不在**底部区域，控制栏**自动收起**；
- 收起时**彻底关掉毛玻璃**（反正看不见，算它纯属白费电）；
- 鼠标往下一滑，控制栏**照常弹出**，手感一点没变；
- 控制栏可见时的**外观和以前一模一样**。

## 🔧 修复的 7 个缺陷

### 1. 无边框窗口"关不掉"（最要紧的一个）

**你能感觉到的现象**：你在大屏幕（比如 4K 显示器或副屏）上用过播放器，之后换到小屏幕（比如笔记本 1080p）打开——**窗口比屏幕还宽，右上角的"关闭/最小化"按钮跑到屏幕外面**，你**关不掉也拖不动**。

**原因**：源码里"把窗口尺寸限制进屏幕"这段保护，被一段"判断窗口位置是否还在屏幕内"的代码挡在了后面。当窗口位置被判为"跑到屏幕外"时，位置被清空，那段**尺寸保护也跟着被跳过了**——恰恰是最需要它的场景失灵。

**修复后**：尺寸保护改为**无条件执行**。位置信息还在就按它所在屏幕限制，位置已失效就按主屏幕限制。实测复现并确认修复。

### 2. 点过按钮后，快捷键全部失灵

**你能感觉到的现象**：你点了一下"播放"按钮，然后想按**方向键快进**——**没反应**。F11 全屏、S 截图、M 静音，**全都没反应**。

**原因**：快捷键处理在开头写了一句"焦点在按钮上就跳过"。而**按钮被点过之后会一直保持"焦点"**，于是所有快捷键都被这句话吞掉了。

**修复后**：只有输入框之类的打字控件才完全让路；**按钮只在空格/回车这两个"按钮自己的键"上让路**（保留原来的防重复触发），其余快捷键恢复正常。已用真实内核实测确认。

### 3~7. 其余五个（偏底层，你不会直接看到，但都真实存在）

- **换片自动贴合窗口的位置，被当成你的"偏好"存下来**，覆盖了你自己调好的窗口尺寸/位置；
- **缓存清理时可能误删"另一个窗口正在转换的半成品"**（多窗口同时用时，概率很小但存在）；
- **一次选中很多文件"打开方式"时，会绕开窗口数量上限**，可能开出一大堆窗口；
- **视频分辨率参数缺了上界检查**（异常输入可能算出无效窗口尺寸）；
- **修正了两处与实测矛盾的代码注释**（这两处错注释还误导过一次审查，险些导致错改）。

## 🧹 清理的无用东西

删掉了一批"没人用"的代码/样式（不影响任何功能）：

- 两条没有任何元素使用的 CSS 规则、一个多余的样式类名；
- 一个从来没被传入过的函数参数；
- 转换器里 4 个"对外暴露但无人调用"的导出；
- 一处写错了的注释（说返回 `{video, audio, all}`，实际还含别的字段）；
- `.gitignore` 补上了漏掉的 `.qwen/` 忽略规则。

**没有做的事（有意）**：有些代码确实"长得像重复"，但都属于**惯用写法**，合并了反而更难读——按"能简单就别复杂化、不随意重构"的原则，**保持原样**。

## ⚠️ 如实说明

- **本版没有新功能**，是一次"瘦身 + 减负 + 修 bug"的版本。
- **已知遗留（本版有意未动）**：
  - **多窗口的设置/历史会互相覆盖**——每个窗口各存一份，后保存的盖掉先保存的。根治要把存档集中到主进程，属架构级改动。
  - **转换失败只提示原因，没有"用其它播放器打开"的按钮**——那是新功能，不在本版夹带。
  - **边转边播、多音轨选择、内嵌字幕烧录**：仍按原计划未做。
- **老格式转码速度取决于机器**：有独显走硬件编码会快很多；本机已实测启用 NVIDIA 硬件编码成功。
