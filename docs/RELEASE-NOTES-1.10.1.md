# BBPlayer 1.10.1

> English version: [RELEASE-NOTES-1.10.1-EN.md](./RELEASE-NOTES-1.10.1-EN.md)

**一句话**：这是一个**全量性能瘦身、流畅度升级与稳定性加固**版本——老格式二次打开**免探测直接秒开**、播放列表与进度条实现**零回流 GPU 动画**、暂停后自动**挂起音频引擎省电**、主进程文件与磁盘缓存全面异步化减少卡顿、新增自动更新 **HTTPS 安全强校验**，并将无界面自动化测试补强至 **36 项转换层 + 51 项渲染层 + 全仓架构防退化契约**。

---

## ⚡ 性能、内存与流畅度优化

1. **老格式二次打开免探测秒开**：AVI / FLV / WMV / TS / RMVB / VOB 等需要内置 FFmpeg 转换的格式，在二次打开时会于启动探测前先直接命中本地三档磁盘缓存，真正做到不启子进程直接秒开。
2. **界面零回流与长列表提速**：
   - 侧边播放列表面板改用固定位置 + `translateX` 纯 GPU 合成滑入动画；
   - 进度条固定命中热区，悬停改为 `scaleY(1.8)` 缩放，不再反复触发页面重排（Reflow）；
   - 播放列表项开启 `content-visibility: auto`，长播放列表滑动不卡顿；
   - 主题阴影、频谱渐变色带与危险提示文字全部收口到 CSS 语义变量，切浅/深主题更统一。
3. **后台省电与画布复用**：
   - 新增音频引擎闲置自动休眠：暂停播放 8 秒后若仍未继续，自动挂起 `AudioContext` 释放音频硬件线程，点播放瞬间无缝恢复；
   - 音乐模式封面取色画布改模块级复用，频谱画布在尺寸未变时不重分配缓冲，切歌更轻快。
4. **并发探测与轻量历史记录**：
   - 外挂同名字幕自动探测从串行改为 `Promise.all` 并发查找，同时兼容按格式顺序选用；
   - 播放历史面板废弃每条独立绑定事件，统一并入列表容器单一事件委托；删除单条记录时只移除对应条目节点并更新计数，不再整页重建；
   - 拖动音量条或滚轮调音改为 250ms 防抖写入配置（关闭软件前自动兜底刷盘），历史记录仅在超出 200 条上限时排序裁剪。
5. **主进程全面异步化与缓存**：
   - 音乐封面搜索改为单次异步读取目录并建表匹配，替代原先多次串行磁盘探测；
   - 窗口日常状态保存与缓存清理均走异步文件操作；多显示器合并边界加入懒缓存，拖拽窗口更跟手。

## 🩹 缺陷修复与安全边界加固

| # | 优化/修复内容 | 改进效果 |
|---|---|---|
| 1 | 程序化贴合窗口大小与位置改用精确坐标/尺寸一次性豁免 | 不再因为固定时间窗锁而“吞掉”用户紧接着的手动拖拽调整，竖屏小窗并补充 320px 最小高度保护 |
| 2 | 自动更新器新增 `isSafeHttpsUrl()` 强校验 | 在下载安装包与浏览器跳开发布页前均拦截非 `https:` 链接，守住下载与外跳边界 |
| 3 | 自动更新下载流程异步化与进度节流 | 下载失败异步清理 `.part` 临时文件；任务栏下载进度条增加 120ms 节流不刷爆系统 IPC；便携版命名正则兼容带 `v` 及连字符写法 |
| 4 | FFmpeg 进度帧边界累计解析与在途探测取消 | 防止高码率转码时进度报文被截断导致百分比抖动；换片取消可同步中止在途探测；`.part` 原子改名落盘后再解除临时文件保护 |
| 5 | `ffmpegPath` 变更时自动清空探测缓存 | 切换/重配内置 FFmpeg 路径后不会沿用旧探测缓存 |
| 6 | 非原生直出与缓存命中提前返回 | 未实际进入转换流程时不再对界面误闪“准备转换”提示 |
| 7 | 损坏存档数值与空文件拖放拦截 | `restoreSettings()` 拦掉 `Infinity` / `NaN` 等异常字幕字号和偏移；拖放过滤 0 字节文件与无后缀文件夹 |
| 8 | 空状态复位与列表删除防重复渲染 | 清空播放器彻底清理标题栏隐藏计时器、重置标题/时间/进度条；删除正在播放项且仍有后继时不再重复重建两次 DOM |

## 🧪 自动化验证与防退化基建

- `npm run verify` **全绿通过**：
  - 扩展名对账：原生视频 8 + 需转换视频 11 + 音频 6 = **25 项** 100% 一致；
  - 转换层自检（35 → **36 项**）：新增“非原生文件二次打开直接命中磁盘缓存免探测直出”测试；
  - 渲染层自检（48 → **51 项**）：新增历史面板事件委托与就地删除、极端 `Infinity` 损坏设置拦截、并发同名字幕自动加载等 3 大类回归锁；
  - 接线与架构防退化检查（`verify-wiring.js`）：新增第 10 节架构契约，守护 HTTPS 强校验、`.part` 异步清理、零回流 CSS、`AudioContext` 休眠与防同步写盘阻塞等关键纪律。
