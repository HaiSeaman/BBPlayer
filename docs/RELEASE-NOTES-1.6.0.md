## BBPlayer v1.6.0 — "安静玻璃"低占用视觉重做

本版本以「**简洁 · 无边框 · 资源占用最低**」为设计语言，对界面视觉做了全面重做，并修复了一个影响日常使用的标题栏交互问题。

### ✨ 全新"安静玻璃"设计语言

- 界面全面减负：移除多余模糊与发光效果，播放器的英雄回归画面本身
- 毛玻璃质感仅保留底部功能栏一处，其余面板改为干净实底，**GPU / CPU 占用显著下降**
- 圆角、间距、强调色全部 token 化统一（四档圆角刻度），品牌青只出现在进度、播放键与正在播放条目三处

### 🎛️ 控制栏重排

- 全部按键"幽灵化"：去边框、去投影，悬停才浮现浅色底，激活只染图标色
- 1px 细分隔线划分四个职能组：`倍速 · 比例 · CC`｜`音量`｜`外观 · 模式 · 截图 · 旋转`｜`全屏 · 列表`
- 播放键是整个控制栏唯一的实心强调：40px 品牌青圆角方形，无渐变无发光

### 🪟 窗口控制按键贴角

- 最小化 / 最大化 / 关闭改为 **44×42 矩形按键**，贴合窗口右上角（原生无边框应用样式，不再是悬浮小圆片）
- 关闭键悬停纯红，一目了然

### 🖱️ 标题栏交互修复（重要）

- 修复"鼠标移到顶部菜单栏经常不显示"：根因是 OS 级拖拽区会吞掉鼠标事件，导致热区唤出失效
- 标题栏拖拽改为事件驱动的平滑实现，热区唤出 / 悬停保持 / 停放不收起全部稳定
- 新增：**双击标题栏 = 最大化 / 还原**

### 📃 播放列表现代化

- 面板加宽至 320px，正在播放条目显示**左缘强调条 + 三根跳动小均衡器**（暂停即静止）
- 序号改为等宽两位数；操作按钮统一为 SVG 图标（新窗口 / 移除）
- 长列表上下缘渐隐，滚动更顺滑

### ♿ 细节与可访问性

- 弹出菜单左对齐 + 指示点标记当前选中项
- 键盘导航焦点环、尊重系统"减少动态效果"偏好
- 清理 10 组闲置样式变量，代码更精瘦

### 🛡️ 正确性修复

- 修复切换曲目时播放列表均衡器指示残留的问题
- 全量代码审查通过（renderer.js / main.js / preload.js / index.html）
