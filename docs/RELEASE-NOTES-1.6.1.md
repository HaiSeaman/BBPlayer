## 🌈 v1.6.1 — 彩虹品牌主题来了！

BBPlayer v1.6.1 把品牌视觉全面换装为**彩虹渐变**：从应用图标到播放控制栏，一套完整的
红→橙→黄→绿→青→蓝→紫色彩语言贯穿始终，同时完成了一轮双轴全量代码审查（正确性 +
过度设计），修复 3 个 BUG、清理约 50 行冗余代码。

## ✨ 新特性与改进

### 🌈 彩虹品牌主题
- **全新应用图标**：播放三角重制为完整彩虹渐变（深色描边 + 透明底），覆盖应用窗口、
  任务栏、打包 EXE 与全部媒体文件关联图标（.mp4 / .mkv / .mp3 等 25 种格式）；
- **界面品牌元素同步换装**：标题栏 BBPLAYER Logo、启动页大 Logo、音乐封面占位区。

### 🎵 播放功能栏彩虹化
- **播放 / 暂停键**：改为透明底色，播放三角与暂停双竖条图标本身呈连续彩虹渐变，
  与应用图标同款视觉语言；
- **彩虹进度条**：采用恒定色带技术——色带位置固定不随进度压缩，任意进度下都是
  完整的红→紫渐变；
- **窗口按键提亮**：右上角最小化 / 最大化 / 关闭的图标从灰色改为纯白（与软件名同色），
  悬停时浮现深色高亮块，看得清、点得准。

### 🛡️ BUG 修复（双轴全量审查）
- 修复播放列表「移除 / 新窗口」按钮点击在图标图形上时事件穿透、误触发播放的问题；
- 修复删除播放失败的条目后重新添加同名文件仍被自动跳过的「永久拉黑」问题；
- 修复键盘快进键对无时长媒体的校验漏洞。

### 🧹 工程瘦身（净约 -50 行）
- 视频画面与标题栏两套重复的窗口拖拽实现合并为单一函数；
- 字幕扩展名白名单从 4 处硬编码收敛为 `shared-subtitle-exts.js` 单一来源；
- 彩虹色标 22 处硬编码收敛为 7 个 CSS 变量，改品牌色只需改一处；
- 清理 4 组死代码变量与常量；扩展名对账脚本挂载为 `npm run verify`。
